# 配置中心 UI 设计系统（B′）规范

- 状态：已确认（2026-10-16，方向 B 融合 RustFS 质感 + 满幅白面工作区）
- 范围：`web/` 的视觉系统与移植契约；领域页面沿用本系统
- 关联：[2026-10-16-web-skeleton-design.md](./2026-10-16-web-skeleton-design.md)、`docs/superpowers/design` 探索稿（工作副本）

## 1. 方向

机构编辑派骨架 × 轻质皮肤：衬线标题、大字距大写微标签、等宽数字承载「机构报告」气质；满幅白面、发丝线、零阴影、4px 小圆角承载「工具」质感。紫色是唯一强调色，只作文字与激活态点缀，不作大面积铺色。

## 2. 设计令牌

| 组 | 值 |
|---|---|
| 表面 | 白 `#FFFFFF`（工作区满幅、侧栏、顶栏、登录表单卡）；登录页画布浅灰 `#F5F6F8` |
| 线 | 发丝线 `#E7E7EC`（全站分隔）；表头线 `#D9D9E0`（仅表头下） |
| 文字 | 墨 `#141519`；次级 `#5C5D66` |
| 品牌 | 强调紫 `#4B1D7E`（字标文字、激活态、主按钮、头像圆点）；悬停深紫 `#3B1370`；激活底 `#EFE9F7`；角色章统一 tonal（管理员紫/编辑蓝 `#2E63CD`/只读灰），单一 `.chip` 体系 |
| 字系 | 正文 PingFang SC / 微软雅黑 13.5px；页面标题衬线 Georgia/中宋 22px/600（`.page-title`）；微标签 10px 大写字距 .18em；数字代码 IBM Plex Mono/Consolas 12px |
| 圆角 | 4px（按钮/输入/行操作/表盒）；其余直角 |
| 阴影 | 零阴影；分层只靠发丝线 |
| 动效 | 仅 150–200ms ease 状态过渡（悬停/按压）；无入场动画 |
| 图标 | MDI outline 系，16px、1.5px 描边单色 |

## 3. 间距系统（基准 4px，步进 4/8/12/16/20/24/32）

- 页面纵向节奏：标题区 → 20px → 工具行 → 16px → 表格；独立区块间 24px。
- 页面内边距 24px（纵）× 32px（横）；侧栏宽 232px、内边距 20px；顶栏高 52px、元素间 12px。
- 表格行高 42px、单元格横向 16px；导航项间 2px、图标与文字间 10px。
- 表单字段间 16px；按钮组间 10px；行内章与文字间 8px。

## 4. 移植契约

- 样式尽量全局：组件默认值集中在 Vuetify `defaults`，通用模式（页头行、章、表单节奏、弹层发丝化）是 `style.css` 全局类；页面组件只保留该页版式特例。
- 令牌以 CSS 自定义属性落在 `web/src/style.css`（`--hairline`、`--ink`、`--accent` 等），Vuetify 主题只承载 `primary/secondary/background/surface` 与边框色；组件不硬编码色值。
- 布局壳（侧栏/顶栏/内容）为全站唯一壳，领域页面不得自带画布或卡片底。
- 登录页为浅色分屏：左画布承品牌文字（紫色衬线字标 + 标语），右白色发丝卡承表单；与工作区共享令牌、不复用布局。
- 本单元不改任何业务行为与 `/api/*` 契约；冒烟回归登录全流程。
